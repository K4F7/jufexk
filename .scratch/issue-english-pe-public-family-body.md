## 问题描述

目录基线已在生产（约 3740 门课 / 公开约 3697）。本票**不重导批准包**，不合并课号身份。

公开浏览层要把教务编号课收成学生能认的名字：

- **大学英语 I–IV / 1–4**（含罗马数字 Ⅰ–Ⅳ）统一显示为 **大学英语**，列表只留一条
- **体育 1–4 / 大学体育 1–4** 仍是教务伞形课名，不公开；公开用网球、篮球等专项课名（现有行为，本票只补 `大学体育1–4` 别名）

同课号不同课号不得合并（ADR-0006）。涉外 / 艺体 / 运训 / 预备级不归并。

## 建议

沿用体育专项族的预计算 `family_label` / `canonical_course_id`：

1. 精确匹配 `大学英语1|2|3|4|I|II|III|IV|Ⅰ|Ⅱ|Ⅲ|Ⅳ` → 族名 `大学英语`。不要 `LIKE '大学英语%'`。
2. 公开列表 / 搜索 / 教师任课表只出该族规范课（优先有文字评价，否则 `大学英语I` / `1` / `Ⅰ`，再 `id`）。展示名走 `publicCourseDisplayName`。
3. 课程详情教师并集按族聚合（与击剑 1/2 相同）。评价流仍按请求课号，不改 #359。
4. **投稿选项** `/api/courses/options` 仍列出大学英语 I–IV 教务名，不归并，避免新评价绑错课号。
5. 管理后台仍显示教务课名。目录基线 `courses.name` / 课号不改。
6. `大学体育1–4` 加入伞形课名隐藏表；体育专项族与虚拟瑜伽/武术保持现状。
