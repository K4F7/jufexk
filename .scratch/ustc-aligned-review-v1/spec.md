第一版任课评价问卷先对齐 USTC 评课社区的全站同一套四道三档题；体育课和网课也不换题。分类与 `mooc` 标签继续用于浏览，六类评价规则留下供以后加特有题。

## Problem Statement

第一版任课评价问卷按课类和网课标签换题：线下要答点名频率，网课藏点名，体育/英语/专业课虽然题目相同，却被设计成以后会分叉的六套规则。投稿者面对的是「上课表现 / 点名 / 给分 / 考核压力」的 1–5 分，补充说明可以不写。我们希望第一版先对齐 USTC 评课社区那种全站同一套四道三档题，体育课和网课也不换题；站内分类只用来找课。补充说明改成必填短文。六类评价规则留下，等第一版跑通再加特有题。

## Solution

所有课程的任课评价都用同一套必答题：课程难度、作业多少、给分好坏、收获多少（各三档），加上 1–5 的本次推荐度，以及至少 10 字的补充说明。评价仍绑定已有任课关系。课程上的评价规则键和 `mooc` 标签继续存在，但第一版不因此换题或藏题。四道三档题方向不一致，不做成维度均分；课程 × 教师的评分只汇总本次推荐度。公开文字流展示四档主观标签和正文。已发布的旧规则版本只读、不回填。

## User Stories

1. As a 已登录同学, I want 体育课和专业课用同一张问卷, so that 我不用猜这门课要答哪套题
2. As a 已登录同学, I want 网课也不少题、不藏点名, so that 第一版体验和线下课一样简单
3. As a 已登录同学, I want 用「简单 / 中等 / 困难」回答课程难度, so that 我按感受勾选而不是打 1–5
4. As a 已登录同学, I want 用「不多 / 中等 / 超多」回答作业多少, so that 作业负担有口语化选项
5. As a 已登录同学, I want 用「超好 / 一般 / 杀手」回答给分好坏, so that 给分是主观感受而不是分数统计
6. As a 已登录同学, I want 用「很多 / 一般 / 没有」回答收获多少, so that 收获也是主观三档
7. As a 已登录同学, I want 另外给一个 1–5 的本次推荐度, so that 综合判断和四道感受题分开
8. As a 已登录同学, I want 必须写至少 10 字补充说明才能提交, so that 每条新任课评价都有一段可读文字
9. As a 已登录同学, I want 四道三档题和推荐度都必答, so that 不能只评总分或只评其中一维
10. As a 已登录同学, I want 提交前先选课程再选任课教师, so that 评价仍绑定已有任课关系
11. As a 已登录同学, I want 找不到课时走目录补充申请且随附同一套问卷, so that 补录对象和评价规则一致
12. As a 已登录同学, I want 补充说明超过长度上限时被截断或拒绝有明确提示, so that 我知道正文写到哪
13. As a 已登录同学, I want 人机验证和登录门槛保持不变, so that 第一版只改题目不改投稿门禁
14. As a 浏览同学, I want 在公开文字流里看到四维的中文标签而不是一个「维度均分」, so that 我不会把「杀手」和「收获很多」平均成一个数
15. As a 浏览同学, I want 课程页和教师页的评分数字仍是推荐度均分并带样本数, so that 跨课比较继续只用同一道推荐度
16. As a 浏览同学, I want 没有补充说明的旧评分行继续不进文字流, so that 历史选填正文的规则不被改写
17. As a 浏览同学, I want 带旧规则快照的评价若仍显示维度均分则只针对旧快照, so that 旧 1–5 四维不被假装成新三档
18. As a 浏览同学, I want 用体育 / 英语 / 慕课等筛选找课, so that 分类还在，只是不再换问卷
19. As a 带 mooc 标签课程的浏览者, I want 课程仍显示网课标签, so that 我知道授课形式，但写评题目不变
20. As a 管理员, I want 新提交由后端写入规则键和版本、不采信前端自报规则, so that 投稿者不能改自己适用哪套题
21. As a 管理员, I want 旧评价的规则字段不被回填, so that 规则启用前的行保持原样
22. As a 后续规则作者, I want 六类评价规则键保留且当前最新版本题目相同, so that 以后只追加新版本加特有题
23. As a 后续规则作者, I want 已发布版本永不改题目, so that 历史快照能按当时版本译成标签
24. As a 后续规则作者, I want offlineOnly 机制保留但第一版最新题集不用它, so that 以后网课可以再藏仅线下题
25. As a 实现 agent, I want 课程详情和课程选项读出的适用题目带三档选项文案, so that 写评价页不用硬编码标签
26. As a 实现 agent, I want 缺维、非法档位、过短补充说明在接口层被拒绝, so that 绕过前端也不能写入
27. As a 实现 agent, I want 公开评价读出口能给出四维展示标签, so that 列表不必自己猜 1/2/3 的含义
28. As a 站点维护者, I want 领域词汇写明补充说明必填、维度均分不再用于这四道三档题, so that 以后讨论不再沿用「空正文也是有效评分」的第一版说法

## Implementation Decisions

- 只改问卷与展示，不改任课绑定、登录/Turnstile、目录导入、浏览筛选口径。
- 总推荐度继续 1–5，不引入半星或 10 分存储。
- 不做「只写文字不评分」。
- 评价规则仍是代码内版本化定义；六类键保留；最新版本四道三档题完全相同。
- 按「已发布版本不改」：旧核心只读；新提交写新版本。不回填。
- 维度定义自带三档选项；校验按该维选项收分，不再假定所有维都是 1–5。
- 适用题目仍由「课程规则 + 课程标签」唯一计算点算出；第一版最新题集不因 `mooc` 删题。
- 写入接口（任课评价、目录申请随附评价）共用同一套快照校验；规则键与版本由后端按课程当时状态写入。
- 补充说明去空白后长度属于闭区间 10 到 1200。
- 公开文字流对最新四维快照展示四个主观标签，不输出维度均分；课程/教师聚合分只来自本次推荐度。
- 领域文档与 ADR：新 ADR 修订既有版本化规则 ADR；词汇表改「补充说明」和「维度均分」的第一版含义。
- 写评价页用官方 Radio 组渲染三档文案，去掉网课藏题提示。

四道三档题（各存 1 / 2 / 3）：

- `difficulty` 课程难度：简单 / 中等 / 困难
- `homework` 作业多少：不多 / 中等 / 超多
- `grading` 给分好坏：超好 / 一般 / 杀手
- `gain` 收获多少：很多 / 一般 / 没有

## Testing Decisions

- 只测外部行为：接口收拒、课程读出的适用题目、公开流字段、写评价页可见题与提交载荷。不测内部函数名或列是否存在。
- 主缝：现有 Workers HTTP 测试（投稿、课程详情/选项、目录申请随附评价、公开评价投影）。
- 写评价页继续走现有 Playwright 投稿缝（题干、三档文案、网课不再藏题、补充说明必填）。
- 规则模块单测只覆盖适用题目、快照校验、旧版本只读、禁止四维均分这些已存在的计算点，不新开产品缝。
- HTTP 或浏览器失败时，以适用题目计算点为准，不得另写一套过滤策略。

## Out of Scope

- 即时公开、匿名勾选、学期必选、只写文字不评分、半星或 10 分总分
- 体育/英语/思政等特有题、网课再藏题
- 改目录身份、历史评价导入、人工审核产品策略、推荐教师标签
- 把本次推荐度改成由四维派生

## Further Notes

参考 USTC 评课社区公开实现：四道三档题全站共用，体育和慕课只是列表筛选。选课志第一版对齐题目，不对齐绑定与发布策略。实现按子工单推进；工作流 `ustc-aligned-review-v1` 每次只做一张未阻塞工单。
