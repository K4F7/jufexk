# 历史评价采用分级审核：LLM 分流、人工裁决

1150 条 OCR 历史评价候选逐条人审成本过高，但站点公信力建立在「公开内容均经人工审核」之上。我们决定采用分级审核：双中小模型 agent 对抗分析 + 大模型仲裁只承担**分流**，不构成批准。满足全部准入条件的记录进入高置信队列，由人工批量一键批准；其余一律逐条人审。人类保留最终签字权。

## Considered Options

- **全量逐条人审（LLM 仅提供纠错建议）**：浪费对抗性设计的全部价值，1150 条的人工成本不可接受。
- **仲裁即批准、人工只抽查**：违反「未经人工确认不得公开」的既有硬约束，动摇站点公信力，被明确否决。

## 高置信队列准入条件（严格版）

结构性硬条件（任一不满足即出局）：

1. 课程与教师均唯一匹配课程目录，且该任课关系存在；
2. 无结构歧义标记（多教师横行、跨截图继承、截断、开课班歧义）；
3. 不在疑似重复清单中（重复判定不交给 LLM）；
4. 证据链完整：来源截图文件名、表格位置、OCR 原文、正文四者齐全。

LLM 条件：

5. 双 agent 在课程映射、教师映射、正文三项上全部一致；任何一项分歧 → 逐条人审，仲裁只作为人审推荐；
6. 仲裁模型确认通过；
7. 正文含疑似错字或异常字符、或任何 agent 提出正文修改 → 逐条人审。高置信队列只收正文零修改的记录。

门禁：

8. 冒烟测试达标才开闸：LLM 流水线在人工核对的金标准上运行，高置信桶内课程/教师映射错误必须为 0；出现任何错映射即收紧条件重测。

## 金标准的来源

以交接的人工比对交付物（`handoff/课程与历史评价人工比对需求.md` 所要求的 `历史评价校对` 成果）为主，先抽查其质量；对覆盖不足的工作表和关键陷阱类型补人工核对。金标准必须刻意包含「应当被拦下」的陷阱样本——结构歧义、疑似重复、稳定误识别（如「维性代数」）——只有干净样本的金标准测不出错放率，而错放是唯一不可接受的失败模式。
