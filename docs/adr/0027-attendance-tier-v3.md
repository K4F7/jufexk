日期：2026-08-24

修订 [ADR-0023](./0023-ustc-aligned-four-tier-questions.md)：六个规则键各追加 v3，公共核在四道三档题（课程难度、作业多少、给分好坏、收获多少）后增加第五题 `attendance` **考勤松紧**，选项为宽松 / 一般 / 严苛（值 1 / 2 / 3，2026-08-24 用户锁定文案）。题干保持主观报告口径，不叫「考勤难度」，也不同时出「点名频率」。

- `attendance` 标 `offlineOnly`：带 `mooc` 标签的课不展示、不必答；提交中对慕课仍带 `attendance` 键一律拒绝。六类线下课共用同一题干与选项，不做成体育特有题。

- 已发布的 v1（1–5，含旧「点名频率」）与 v2（四道三档）快照只读、不回填、不改写；公开条目按各自快照的版本翻译标签——v2 行四个标签，v3 行五个标签，缺考勤的旧快照不伪造。
- 投稿接口、投稿页与目录申请随附评价继续共用同一个适用题目计算点（`applicableDimensions`）。
