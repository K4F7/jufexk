# 排课模拟只做电脑端，窄屏只弹一次告示

_2026-08-25：[#565](https://github.com/K4F7/jufexk/issues/565) 明确 `/schedule` 不另做手机布局。_

排课模拟是周课表编排界面，只按电脑端交付。窄屏（`max-width: 639px`）进入时用 HeroUI AlertDialog 弹一次告示：本功能只支持电脑端，移动端不适配 UI。同一浏览器本机记住已读，关掉后仍可继续看页，不拦截功能。

## Consequences

- 不要为 `/schedule` 再做第二套手机布局、堆叠课表或手机专用表单。
- 现有的窄屏防溢出处理可以保留，但不因此扩展成手机适配。
- 后续「全站移动端优化」不包含排课模拟。

## Considered Options

- **电脑端布局 + 一次告示（采纳）**：提示用不适配的事实，不假装做好了手机版。
- **为排课模拟做完整手机 UI**：工作量大，且课表交互不适合窄屏，否决。
- **窄屏直接禁止进入**：过度拦截，否决。
