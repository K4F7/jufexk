# 目录基线以批准数据包原子导入

目录基线以版本化 `catalog-baseline.jsonl` 批准数据包作为唯一权威交付物，CSV 和校对表仅用于异常复核。覆盖、金标准、确定性与冲突门禁全部通过且异常项均有终态后，系统自动编译并批准数据包，不再要求第二次人工批次确认；正式写入生产数据库仍由管理员执行一次明确导入操作。大批准包按块断点上传到隔离暂存区，全部块经整包哈希和完整预览校验后，才在单次事务中发布课程、教师与任课关系。基线导入只允许在三类目录对象均为空时运行，成功后记录批准包身份并永久关闭该入口。该选择需要新增专用导入协议，但避免首次基线与存量对象隐蔽合并或因中途失败形成半成品目录。
