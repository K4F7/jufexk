# 历史体育评价按课名 × 老师绑定，并实行体育一师一课

历史资料「体育课」表以可见课名与可见教师名组成课名 × 老师对；可见课名是历史别名映射的输入，落到目录已有课号，不创建新课程。目录里已存在的一位体育老师只对应一门体育课；重名按体育来源教师名绑定，表上姓名不得直接新建教师。课与师都在、只缺任课关系时走 [ADR-0017](./0017-append-only-official-relation-additions.md) 的只新增路径，本批不得改写或重放已导入的历史评价批次。

## Considered Options

- **按体育1 / 体育2 建课或分组**：那是表上的分组描述，不是课程身份，否决。
- **用可见课名新建课程**：目录已有对应课号与名称变体，否决。
- **重名老师按无后缀姓名或非体育身份绑定**：会把体育评价绑到错误教师，否决。
- **表上姓名直接新建教师**：可见教师名不是来源教师身份，否决。
