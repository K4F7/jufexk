# 用户补录走申请队列，不直接写目录

课程目录是管理员严格策展的：评价必须绑定目录中真实存在的课程和任课教师，这是评价可信度的地基。当用户在投稿时找不到自己的课程或教师，他们提交的是一条**目录补充申请**，进入管理员审核队列；审核通过后才真正创建目录对象。申请附带的评价随申请暂存，对象建立后自动进入评价审核队列——用户不需要回来重填。

入口有两处：投稿问卷内的「找不到我的课程/教师」，以及页面底部的常驻入口。

## Considered Options

- **用户直接创建、事后核（先上车后补票）**：目录会混入错别字、重复与恶意对象，违背「未经人工确认不进公开数据」的全站原则（与历史评价审核是同一条红线），否决。
- **纯反馈信箱**：实现最省，但用户投稿冲动最宝贵，让他留言等通知等于流失，否决。
