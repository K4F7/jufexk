# 关注 / 推荐 / 不推荐与评分脱钩

课程 × 教师详情上的关注、推荐、不推荐是登录普通用户给出的关系级信号，不是评分。

- 作用域是任课关系，每人每关系至多关注一次、至多一种推荐立场（推荐或不推荐互斥）。
- 三个计数与 viewer 状态随详情 `teachers[]` 和目录 `view=relations` 行下发；写接口为 PUT/DELETE，带幂等键。
- 推荐 / 不推荐 **不计入** 推荐度（`overall` 均分）、#373 四维聚合、目录 `sort=rating` 或任何公开排序。
- 课程元信息里的选课类别 / 教学类型 / 课程层次由公开类别、评价规则键与 `mooc` 标签派生，不新增教务列。

权威规格：GitHub issue #410
