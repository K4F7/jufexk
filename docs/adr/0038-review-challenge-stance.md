# 评价质疑与认可互斥；访客可投票；质疑过多则收起

公开文字评价的倒拇指是**质疑**，与认可组成一人一条的评价立场（认可 / 质疑 / 无），不是课程页关系推荐的「不推荐」，也不使用「踩」或「不认可」。

- 资格与幂等跟认可相同；写在独立表，不改 `review_endorsements` 外键。建立一侧时撤回另一侧。
- 投票不必登录。已登录活跃账号用 `users.id`（禁言仍能看见自己的票，但不能再写）；访客用 HttpOnly 签名 cookie `jufexk_voter`（`id.hmac`），库内为 `guest:<id>`。写请求仍要 Origin + CSRF。登录后不合并访客历史票。写评论 / 回复仍须登录。
- 收起规则：`质疑 >= 3` 且 `质疑 > 认可` 时对所有人折叠正文；浏览者自己质疑则立刻对自己折叠。占位一律为小字「该评价因不受欢迎被折叠」，没有展开/收起按钮。撤回自己的质疑且未达公开阈值时正文自行恢复。
- 覆盖当前任课评价、公开历史评价与可认可的已批准历史资料行；回复只保留认可，不扩质疑、不收起。
