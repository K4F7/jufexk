# 目录导入只新增，修正走后台人工编辑

课程目录的更新机制采用最简语义：导入器**严格只新增**，永不修改或删除存量。身份键为：课程=课号+课名，教师=姓名+院系，开课班=课程+学期+班号；键已存在的行在预览中标注「已存在」并跳过。课程课号允许为空，因此必须与课名共同判定身份，避免所有空课号课程互相冲突。开课班按学期自然新增，旧学期数据自动成为历史，无需归档动作。

一切修正不走导入，走后台人工编辑：改学分、改课名、改教师院系都由管理员手工修改同一个对象，评价历史不断裂。

## 已知场景的处理

- **教师转院系**：视为同一人，导入前由管理员手工修改该教师的院系字段，绝不新建同名教师。导入预览发现「同名教师但院系不同」时高亮警告，交人工判断是调动还是重名。
- **初始导入有错**（错学分、错课名等）：通过后台编辑修正，不通过重导入。

## Considered Options

- **三桶差异导入（新增/变更/归档）**：语义最完备，但实现成本高；在「存量基本不变、变更极少」的现实下收益不成比例，否决。
- **整学期替换**：一次错误导入毁掉一学期，与保留审计证据的原则冲突，否决。
