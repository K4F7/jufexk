# 日常目录导入只新增，修正走后台人工编辑

> 本 ADR 只约束既有日常 CSV 导入。教务目录基线不使用该入口：教师来源身份见 [ADR-0004](./0004-source-teacher-identity.md)，课程来源身份见 [ADR-0006](./0006-course-code-source-identity.md)，不导入开课班，原子基线协议见 [ADR-0010](./0010-atomic-catalog-baseline-package.md)。本 ADR 的只新增与人工修正原则继续有效。

既有日常 CSV 导入器**严格只新增**，永不修改或删除存量；键已存在的行在预览中标注「已存在」并跳过。Issue #34 落地 ADR-0004 与 ADR-0006 后，日常导入也统一要求非空课号和来源教师名，并只按这两个来源身份字段定位课程与教师；早期允许空课号、按课号+课名或姓名+院系识别的兼容语义已废止。日常导入仍支持按课程+学期+班号新增开课班。

一切修正不走导入，走后台人工编辑：改学分、改课名、改教师院系都由管理员手工修改同一个对象，评价历史不断裂。

## 已知场景的处理

- **教师转院系**：视为同一来源教师身份，管理员修改院系字段时不创建新教师，也不断开任课关系或评价。
- **初始导入有错**（错学分、错课名等）：通过后台编辑修正，不通过重导入。

## Considered Options

- **三桶差异导入（新增/变更/归档）**：语义最完备，但实现成本高；在「存量基本不变、变更极少」的现实下收益不成比例，否决。
- **整学期替换**：一次错误导入毁掉一学期，与保留审计证据的原则冲突，否决。
