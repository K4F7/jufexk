# 历史评价可认可、回复，管理员可屏蔽或删除

公开历史评价与已批准历史资料行进入统一文字流后，与当前任课评价共用认可、质疑、回复和分享动作。管理员可屏蔽或软删除这些条目；查询作者资料仍只适用于有账号的任课评价。

- 认可与质疑写在独立表，不改 `review_endorsements` 的整数外键。每人每条至多一侧，幂等与 CSRF 与当前认可相同。质疑见 ADR-0038。
- 回复共用 `review_comments.public_id`。历史评价没有作者，顶层回复不发「被回复」通知；回复他人的回复仍通知被回复者。
- 屏蔽 / 删除用 `blocked_at` / `deleted_at`。访客看不到已屏蔽或已删除条目；管理员会话仍能看到已屏蔽条目。
- 不计入评分或推荐度，不回填作者。

权威规格：GitHub issue #677
