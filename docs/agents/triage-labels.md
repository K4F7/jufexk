# Triage 标签

各 skill 以五个规范的 triage 角色说话。本文件把这些角色映射到本仓库追踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库追踪器中的标签 | 含义                     |
| -------------------------- | -------------------- | ------------------------ |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该 issue   |
| `needs-info`               | `needs-info`         | 等待报告者补充信息       |
| `ready-for-agent`          | `ready-for-agent`    | 已完整定义，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现             |
| `wontfix`                  | `wontfix`            | 不予处理                 |

当某个 skill 提到一个角色（例如「打上 AFK-ready 的 triage 标签」）时，使用表中对应的标签字符串。

如果日后改用别的标签命名，只改右列即可。
